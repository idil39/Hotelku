# HotelKu

## Tentang Website

HotelKu adalah aplikasi web manajemen dan pemesanan hotel berbasis Laravel.

Website ini dibuat untuk membantu pelanggan dalam melihat informasi hotel,
melihat kamar dan fasilitas, melakukan pemesanan kamar, melakukan pembayaran,
serta melihat riwayat pemesanan.

Selain untuk pelanggan, HotelKu juga menyediakan sistem administrasi untuk
membantu admin dalam mengelola data hotel, kamar, fasilitas, booking,
pembayaran, pengguna, dan laporan.

## Tujuan

Tujuan dari pembuatan aplikasi HotelKu adalah untuk menyediakan sistem
informasi hotel yang dapat membantu proses pemesanan dan pengelolaan data
hotel secara lebih mudah, terstruktur, dan efisien.

## Fitur Website

HotelKu menggunakan MySQL sebagai database.

Data yang dikelola antara lain:

- Users
- Room Types
- Rooms
- Facilities
- Bookings
- Booking Details
- Payments
